# 中1理科 図で覚える動物の分類

単元7「動物の体のつくりと生活」と単元8「背骨のない動物・動物の分類」を、図問題中心で学習するブラウザアプリです。

## 機能

- 図だけ見て答えるモード
- 10問ランダムテスト
- 間違いだけ復習
- 単元・分野別の結果表示
- 学習進捗をブラウザに保存（localStorage）
- スマホ・タブレット対応

## 使い方

`index.html` をブラウザで開くだけで動作します。

GitHub Pagesで公開する場合：

1. `Settings` → `Pages`
2. `Deploy from a branch` を選択
3. `main` / `root` を選んで保存

## ファイル構成

- `index.html` 画面構造
- `style.css` デザイン
- `app.js` 問題データと動作
